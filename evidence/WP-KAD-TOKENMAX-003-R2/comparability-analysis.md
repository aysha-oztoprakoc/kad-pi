# Comparability

R2 used the unchanged TOKENMAX-LIVE-001 packet and trust requirement. It is the same audit lineage as LIVE-001 and R1, but a different committed runtime and a newly captured local output. R2 is DEGRADED like R1: two local calls, one repair, validator FAIL. Comparisons are descriptive only; no Pareto claim is made.

R2 improved observability: attempt hashes, byte lengths, provenance, and complete local totals are available. It does not demonstrate improved Qwen reliability.
