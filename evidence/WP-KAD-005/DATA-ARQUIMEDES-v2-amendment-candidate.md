# DATA-ARQUIMEDES v2 Amendment Candidate

**Status: CANDIDATE / AMBER — requires governance review before promotion.**

This amendment adds, without removing existing governance:

1. **MAKE IT WORK** — establish the smallest real end-to-end capability and deterministic proof before broad architecture.
2. **MAKE IT FAST** — measure working behavior, then optimize latency, throughput, context, and resource use.
3. **MAKE IT SAFE / PRIVATE** — harden exposure, secrets, scopes, trust domains, provenance, recovery, and auditability after the working baseline.
4. **LEARN ALONG THE WAY** — convert observations into durable evidence, lessons, routing improvements, skills, and deterministic automation.
5. **TOKENMAXXING != SLOPMAXXING** — optimize accepted engineering/research value per remote token; raw consumption is not value. Track local offload, deterministic offload, avoided remote tokens, context cost, rework, and human attention.

These are operating-order amendments, not authority grants. Model output never authorizes mutation or governance promotion. `[HYPOTHESIS]` benefits remain unproven until local evidence supports them.

Provenance: authoritative baseline inspected at `PRIME_DIRECTIVE.md`, `CONTEXT.md`, and `docs/adr/0001`–`0007`. No existing writable global master other than the root Prime Directive was mutated in this work package.
