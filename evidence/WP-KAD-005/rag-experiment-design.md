# RAG microexperiment design (WP-KAD-005)

Conditions are frozen for a later reproducible run: RAG-0 full packet, RAG-1 deterministic keyword retrieval, RAG-2 notification-triggered selective retrieval with STC packets declaring source/version/scope/dependencies/lifetime/provenance. The evaluator uses a fixed two-question set and compares correctness, recall/precision, injected tokens, latency, stale-context errors, invalidations, unaffected-rule evaluations, cache reuse, and local/remote tokens. The completed fixture run is intentionally small: RAG-2 reuses the unaffected Prime fragment while invalidating only the router fragment. Results remain local observations, not a general improvement claim.
