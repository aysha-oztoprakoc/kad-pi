## Fixed full local core

The verdict cannot be changed after results. The predefined local core is:

1. Project-state sovereignty: local workctl state, bounded lifecycle receipts, claims/leases where authorized.
2. Local Git and repository engineering: orientation, diff/history, local commit/worktree operations where authorized.
3. Governance and STC enforcement: preflight, denial paths, owned-path and lease enforcement; no weakening offline.
4. Deterministic local verification: tests, validators, doctors, linters already installed.
5. Local KnowledgePlane and provenance: canonical Markdown, structured evidence, intent/architecture traceability.
6. Local telemetry: append-only local records, validation, hashing, summarization.
7. Bounded local engineering and currently configured local cognitive capability, qualified only for tested tasks.
8. Safe remote degradation, bounded retries, no unauthorized network/authority escalation, data integrity, and clean reconnection.

Remote GitHub, fresh literature discovery, and remote provider acceleration are optional capabilities and must be classified separately.

## Procedure

1. Capture online baseline and exact dirty-tree boundary.
2. Obtain governance preflight for infrastructure mutation and preserve the result.
3. Do not disable WAN without a valid human authorization receipt; restoration must be known first.
4. If authorized, prove WAN unavailable while localhost/LAN remain available, run bounded offline workflows, then restore and reconcile.
5. Run required post-restore validation and independent review.
