# Context policy

Normal KAD context contains only `context_eligible: true`, `review_status: APPROVED`, canonical authority, non-UNKNOWN epistemic records, and necessary governance. Fusion children receive a bounded task-specific context pack with canonical revision and note hashes. Pending, rejected, raw, stale, unverified legacy, and model-generated material is excluded.
