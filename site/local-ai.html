Local AI / Bounded Capability

Local models are tools, not sovereigns.

KAD-PI treats a model binding as an observable capability with explicit identity, scope, resource bounds, and qualification evidence. A model can be locally present without being qualified or active.

QUALIFICATION

State beats implication.

FILE_ONLY means a model weight file exists on disk. LOADABLE means the runtime adapter can successfully initialize it. QUALIFIED means empirical evidence passed the benchmark gate. ACTIVE means live telemetry confirms stable inference.

ECONOMIC ROUTING

TOKENMAXXING over SLOPMAXXING.

Free, deterministic, and local tools are executed first. Premium commercial models require explicit operator authorization. Inferences are budgeted, tracked, and counterfactually evaluated.

02 / Local Stack

Hardware & Execution Infrastructure

HARDWARE ACCELERATION

AMD ROCm & Vulkan

Navi 44 (Radeon RX 9060 XT) and CPU fallback execution with deterministic vRAM quota management and telemetry monitoring via amdgpu_top.

LOCAL MODELS

Stheno & Specialized LMs

Local GGUF models bound to strict task domains (Stheno v3.2 for world/persona simulation; Qwen2.5-Coder for deterministic coding assistants).

ISOLATION

Process & State Safety

Local inference runs in dedicated subprocesses with timeout ceilings and memory caps to prevent system lockups or memory leaks.
