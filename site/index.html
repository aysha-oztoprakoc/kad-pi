01 / Foundation

A research platform, not an oracle.

Local-First

Local models and tools are prioritized. Availability and qualification remain observable states backed by empirical test receipts, not assumptions.

Evidence-gated

Claims are anchored to primary sources, deterministic tests, receipts, and 3-tier epistemic classes. A model asserting success is never evidence of success.

Deterministic authority

Probabilistic interpretation remains strictly outside canonical state mutation. Policy validation, state reconciliation, and acceptance criteria outrank inference.

03 / Core Doctrines

Four operational doctrines govern every execution.

PON — Notify, Don't Poll

Observable state changes produce bounded notifications. Causal dependencies stay explicit, traceable, and tamper-evident.

STC — Declare, Don't Reach

Components explicitly declare their coeffects, required capabilities, and owned paths. Execution boundaries prevent cross-domain contamination.

TDD — Test, Don't Claim

Failing contract test (RED) → minimal fix (GREEN) → refactor → deterministic verification. Observable test behavior outranks model confidence.

GD — Graceful Degradation

Subsystem failure narrows capability rather than corrupting authority. Offline APIs, missing projections, or disabled JavaScript degrade safely.
