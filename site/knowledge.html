KnowledgePlane / Governed Projection

Useful context without a new authority layer.

The KnowledgePlane provides a deterministic mechanism to recover exact facts, preserve provenance, and compile bounded context. Projections are rebuildable; canonical sources remain in charge.

CANONICAL

Sources of Truth

Directives, accepted ADRs, tests, evidence receipts, and human-authored notes outrank compiled indexes and model-generated summaries.

DERIVED

Projections

Generated records carry source hashes, epistemic tiers, and timestamps. If a projection conflicts with a canonical note, the projection is rebuilt or discarded.

DEGRADATION

Graceful Fallback

If specialized retrieval tools or daemon indices are offline, retrieval falls back to deterministic filesystem and linear text parsing without loss of truth.
