PON

Selective reaction

Notifications represent relevant state changes. They are not a reason to create a global event bus or blind polling loop. Conditions and causal dependencies remain typed and inspectable.

STC

Scoped capability

Components declare required coeffects and provided capabilities. Managed effects register inverses; failure unwinds tracked work and reduces the affected capability.

TDD

Executable evidence

Tests exercise seams where behavior is observable: trust filtering, lifecycle recovery, deterministic replay, and graceful degradation.

KnowledgePlane

Derived state stays derived.

Indexes, summaries, retrieval caches, and wiki projections accelerate access. Canonical artifacts outrank them and remain recoverable when adapters fail.
